# Hotel Reservation System

A team-based academic project developed as part of a university course at Qassim University.

The project is a desktop application designed to support hotel reservation management and provide a structured way to manage reservation-related operations.

## Technologies

- Java
- Java Swing
- MVC Architecture
- Database integration
- NetBeans
